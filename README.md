# Volta Pro Solutions website

Responsive static website rebuilt from the two supplied HTML designs, using clean HTML, CSS and vanilla JavaScript.

## Files
- `index.html` - homepage / landing page
- `catalog.html` - searchable, filterable product catalog
- `styles.css` - responsive layout, styling, animations and modal styles
- `app.js` - product rendering, category filtering, search, navigation and quote-form interactions

## Run locally
Open `index.html` in a modern browser. No build step or framework is required. For local development, you can also serve the folder with any static server.


The site uses Google Fonts when an internet connection is available and falls back to system fonts if it is not.
